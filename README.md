Welcome to my personal portfolio website! This is a highly dynamic, interactive, and responsive portfolio designed to showcase my academic background, technical skills, certifications, and development projects. It features a custom **AI Chatbot Assistant** that interactively guides visitors through my profile!

🔗 **Live Demo:** https://portfolio-9oi7.vercel.app/

## 🤖 Featured: Embedded AI Assistant Widget
The highlight of this portfolio is a fully responsive, custom-built **AI Chatbot Console Component**. 
- Acts as a smart interactive virtual assistant for recruiters.
- Understands user queries regarding my intro, education, projects, and certificates.
- Automatically triggers a smooth autoscroll effect to transport the user directly to the relevant section on the screen!

---

## 🛠️ Core Tech Stack & Architecture

This project was developed using a modern, fast, and optimized frontend ecosystem:

*   **Frontend Library:** React.js (Functional Components & Hooks)
*   **Build Tool / Bundler:** Vite (For lightning-fast development and optimized production builds)
*   **Styling & UI:** Tailwind CSS (With modular layout architecture and modern dark-theme aesthetics)
*   **Icons Framework:** React Icons (`fi` feather variants)
*   **Deployment Suite:** Git + GitHub pipeline integrated directly into Vercel Serverless Hosting
